# Blocky Bee — Flappy Bird com temática Minecraft

Specs versionadas em `specs/vN/` (requirements.md, design.md, tasks.md) — siga sempre a pasta de maior número (a atual); veja `specs/README.md` para o padrão. Use `uv` para tudo (`uv sync`, `uv run main.py`, `uv run pytest`); implemente uma task por vez, na ordem, e marque como `[x]` no `tasks.md` dessa pasta ao concluir.

Ao receber um pedido de nova funcionalidade quando a versão atual já estiver com todas as tasks concluídas, crie `specs/vN+1/` (copiando e atualizando os specs da versão anterior, conforme `specs/README.md`) antes de implementar — não edite as pastas de versões anteriores.
